## Part 3: Follow-up

**M:** Okay. So let's, let's wrap up with a few general questions. What would you say you look at first when you're comparing plans?

**P7:** I'd start with the monthly payment, but honestly I'd want to go to the total cost pretty quickly. I'd say those two, together. And then I'd want some kind of, like, a summary. "Based on what you told us, here's what we'd suggest."

**M:** A recommendation?

**P7:** Yeah, I'd love that. I'd definitely use it. I think a lot of people would. I'd want it to explain why, though. I wouldn't just trust a black box. I'd probably cross-check it against the table.

**M:** What about the numbers, do you think they're trustworthy?

**P7:** I'd probably trust them if they showed the assumptions. Like, if I could see the income it was based on, and what rate it's using. I'd want that visible. It'd be nice if it was right there.

**M:** Okay. And if you had to choose between a recommender and, say, a better table, what would you choose?

**P7:** Ooh. That's a good question. I think I'd probably want both. But if I had to pick, I'd probably go with the recommender, because it would save me time. I'd want the table too, though, as a backup. You'd want to be able to verify.

**M:** Right. Okay. Anything else you'd want to see?

**P7:** I think I'd want, like, a timeline. A visual. Where you'd see, here's the path to payoff, and here's where you'd be in five years. I'd probably look at that more than the table, honestly. That's the kind of thing that'd help me get my head around it.

**M:** That's good. Anything else?

**P7:** I'd want to be able to save it. Like, bookmark my scenario and come back. I'd probably use that a lot. I'd come back every quarter and update it.
